# 行動規範 / Code of Conduct

このプロジェクトは [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)（[日本語訳](https://www.contributor-covenant.org/ja/version/2/1/code_of_conduct/)）を行動規範として採用する（ADR-0028）。issue・PR・議論など、このプロジェクトのすべての場に適用する。

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

## 報告 / Reporting

行動規範に反する行いは、メンテナ（[@1ppe1](https://github.com/1ppe1)）に知らせる。公開の場で書きにくい内容は、GitHub の private vulnerability reporting（このリポジトリの Security タブの「Report a vulnerability」）を使ってよい。報告者のプライバシーは守る。

Report unacceptable behavior to the maintainer ([@1ppe1](https://github.com/1ppe1)). For anything you would rather not post publicly, you may use GitHub private vulnerability reporting (Security tab → "Report a vulnerability"). Reports are handled confidentially.

対応は Contributor Covenant 2.1 の「Enforcement Guidelines」に従う。
